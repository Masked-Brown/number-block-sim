How to play
← and → steer the falling block; space drops it. Equal neighbours merge when a block locks: a pair doubles, a triple 4×, a quad 8×, a quint 16×. Each merge scores its result times the chain index, so engineered cascades are the whole game.

The spawn curve drifts upward as your biggest tile grows: low values become rare (never impossible), high values arrive more often. The next box shows the one upcoming block; the possibilities list shows every value that can spawn right now and its odds. Overfill a column and fail to merge back down, and the game ends.
